## Installation

```bash
bunx shadcn@latest add https://ui.usenotra.com/r/perplexity-ui.json
```

This installs the Perplexity primitives into `components/chat-ui` with their model data and required shadcn components. Import each file directly. Every primitive also has its own registry entry; use `https://ui.usenotra.com/r/<file-name>.json` for a single component.

## Components

`perplexity-actions`, `perplexity-citation`, `perplexity-composer`, `perplexity-favicon`, `perplexity-message`, `perplexity-model-icon`, `perplexity-model-selector`, `perplexity-research`, `perplexity-search`, `perplexity-search-timing`, `perplexity-sources-sheet`, `perplexity-thinking`.

The primitives accept content and callbacks from your application. `PerplexityResearch` groups multiple collapsed steps; `PerplexitySearch` shows queries and sources, and `PerplexityResearchStep` accepts any additional activity. The preview is an example; the registry does not include its sample data.
