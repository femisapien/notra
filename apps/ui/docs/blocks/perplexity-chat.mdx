Use **Play demo** above the preview to replay the conversation from the user question through thinking, search and the answer. **Stop** restores the completed example.

## Installation

```bash
bunx shadcn@latest add https://ui.usenotra.com/r/perplexity-chat-block.json
```

The block installs the Perplexity components and their dependencies. Its source is editable after installation.

Pass `messages`, `onSend`, `onStop`, and `busy` to connect your chat state. Each message has an `id`, `from`, and `content`; add `text` to enable copy actions.
